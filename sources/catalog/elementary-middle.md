## Notes and surprises

- **Licensing:** SAMF says its Kangaroo papers may not be reproduced without written permission; the MA says PMC/FMC papers "may not be photocopied"; Noetic says past papers are for registered team leaders only (affects the UCI copies already in the app).
- **SASMO:** each 2019 PDF also contains the 2020 paper; 2020 files have inconsistent headers ("GEP Practice 2020").
- **Austria Felix 2025** begins with a German cover sheet; Austrian answer keys are scanned images.
- **Kangaroo Canada** API key for 2014 has a malformed duplicate "29" entry; 2024-2026 keys are public but papers are not.
- **FMC 2019** "Answers" link actually serves "Instructions 2019.pdf" (answers on the reverse).
- **Continental Math League** paid files are exposed via the WordPress media API - not used.
- **AoPS wiki and amt.edu.au** block curl/WebFetch (Cloudflare 403); use a browser. matematica.pt rate-limits (HTTP 429).
- **Caribou** has ceased operations. **AMC 8 2021** was not held; **2026** has an extra Regional paper. **UKMT JMO/JK 2020** not held.
- **MATHCOUNTS** only keeps the current year online - re-download each spring.
- `sources/pdfs/ukmt/` is shared with the high-school agent; my URL->file map is `manifest_elementary-middle.json`.
